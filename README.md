# Abaya Collection Website

A frontend e-commerce website for an abaya fashion brand, built with HTML, CSS, and JavaScript.

## Features
- 🛍️ **Working Cart** – Add items, adjust quantity, remove items, running total
- ❤️ **Wishlist** – Save favourite abayas with a heart toggle
- 🔍 **Live Search** – Filter products as you type
- 💰 **Price Filters** – Filter by budget range
- 🔔 **Toast Notifications** – Instant feedback on every action
- 📱 **Fully Responsive** – Mobile-friendly with hamburger menu

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript
- No frameworks or libraries — pure frontend

## How to Run
1. Clone the repository
2. Open `main/index.html` in any browser
3. No setup needed

## Project Structure
```
website/
├── images/        # Background and product images
└── main/
    └── index.html # Full website (HTML + CSS + JS combined)
```
